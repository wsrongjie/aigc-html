## 预警与复核：销售违规二级 Tab

位置：预警与复核 → 企微会话 → 二级 Tab「客诉风险 / 销售违规」。

- 客诉风险：完全复用原有企微会话预警队列
- 销售违规：销售违规复核工作台
  - 数据范围：`待认定` + `申诉中`，且来源为 **企微会话 / 客户群**
  - 渠道计数：企微会话 = 客诉 7 + 销售违规 8 = 15；二级 Tab 分别为 7 / 8
  - 左栏：违规预警队列（渠道、等级、重复次数、状态、类型、销售→客户、话术摘要、时间）
  - 中栏：原始企微会话证据（命中话术高亮）
  - 右栏 Tab：复核详情 / 处理轨迹 / 历史违规
  - 复核详情：AI 提示、人工结论、命中口径
  - 历史违规：该销售历史汇总（其他违规 / 红线 / 同类型累计 / 第 N 次触发）
  - 复核动作保留在右侧底部
  - 待认定动作：`认定违规`（复用认定弹窗）/ `判定误报`
  - 申诉中动作：`合规复核`（维持原结论 / 撤销记录）
  - 认定后记录移出本 Tab，进入违规列表「整改中」；申诉后自动回到本 Tab
  - 违规列表的「认定 / 复核」按钮会跳到本 Tab 并选中对应记录
- 其他渠道（文字直播间 / 客诉录音）不显示二级 Tab，自动回到客诉风险

### 顶部筛选卡（2026-11 重构）

- 第一行：渠道分段控件 + 时间范围（两个 Tab 共用）
- 第二行：客诉风险 / 销售违规 Tab + 当前 Tab 专属筛选 + 重置，全部靠左
- 专属筛选紧贴 Tab，下拉宽度 170px，保证「未揭示风险」等选项完整显示
- 客诉风险：只显示「风险等级」，不显示事件类型
- 销售违规：只显示「违规类型」，不显示等级
- 时间：`全部时间 / 近1天 / 近3天 / 近7天 / 近30天 / 自定义`，客诉与销售都生效
- 自定义时间：起止日期内联在时间筛选右侧
- 重置：只重置当前 Tab 的专属筛选 + 时间，不重置渠道
- 文字直播间 / 客诉录音：使用同一筛选卡，显示静态「客诉风险」+ 风险等级 + 时间
- 销售违规队列按违规类型 + 时间过滤；客诉队列按风险等级 + 时间过滤

## 列表字段（11 列）

1. 违规编号 / 来源（来源 + 渠道）
2. 违规时间
3. 销售人员（姓名 + 团队 + 责任主管）
4. **客户（姓名 + 客户编号，只读身份字段）**
5. 违规类型
6. 违规等级（高/中/低 + 第 N 次）

8. 处置阶段（含整改轮次、催办次数）
9. 重复情况（销售第 N 次 + 30 天窗口 / 同类型）
10. 整改时限（剩余/逾期）
11. 操作（详情 / 认定 / 催办 / 验收 / 复核，操作列吸顶）

统计卡：待认定 / 整改中 / 待验收 / 涉及客户（去重，脚注红线数）。

筛选：关键词（客户姓名/编号、销售、编号、话术）、违规类型、等级、时间范围（含自定义）、只看重复违规、重置。

视图预置：全部 / 待认定 / 整改中 / 待验收 / 已闭环 / 申诉中 / 逾期 / 重复违规。

## 详情页结构

```
① 违规事实与证据
② 销售历史违规   ← 新增
③ 认定与整改轨迹
④ 整改与验收
```

② 销售历史违规：
- 统计条：近 90 天其他违规 / 其中红线 / 涉及客户（去重）/ 同类型累计（含本次）
- 明细表：时间 / 客户 / 违规类型 / 等级 / 处置阶段 / 操作
- 排除当前记录，按时间倒序，最多展示 8 条
- 点击「查看」切换到该条违规详情
- 超过 8 条时提供「查看该销售全部记录」→ 回列表并按销售姓名过滤

## 客户身份（不再展开客户维度）

- 客户只作为「这次违规针对谁」的身份字段：
  - 列表：客户姓名 + 客户编号，只读，不可点击
  - 详情 ①：结构化命中里展示「涉及客户 / 客户编号」
- 保留「查看客户会话」：从详情顶部跳到会话档案，定位到该客户
- **不展示客户维度的违规信息**：
  - 无「该客户 N 条违规」、无「最近违规」
  - 无客户档案弹窗
  - 无「该销售对同一客户的历史违规」表
  - 无客户客诉信息与客诉跳转
- 列表统计卡「涉及客户」仅表示本次违规影响到的去重客户数，不代表客户违规明细

## 状态机

```
待认定 ──认定违规──> 整改中 ──销售提交──> 待验收 ──通过──> 已闭环
   │                    ↑                    │
   └──判定误报──> 误报    └────退回整改────────┘
                        整改中 ──销售侧申诉──> 申诉中 ──复核──> 维持 / 撤销
```

- 认定：等级、责任主管、整改期限（3/5/7 天）、整改要求（冻结）、认定说明
- 整改中：仅「催办销售主管」；合规详情不再提供模拟提交整改 / 提交申诉入口
- 待验收：逐项核验、处罚建议（警告/合规培训/扣分/暂停展业/不处罚）、验收通过/退回；**不可提交申诉**
- 已闭环：只读，可查看整改档案；**不支持提交申诉**
- 申诉中：合规复核（维持原结论 / 撤销记录）
- 误报：不纳入考核，保留证据与轨迹
