# 侧栏两级折叠菜单实施计划

目标：将「内容与资料」「业务记录」改为可展开、收起的一级菜单，点击后展示二级页面入口。

授权：用户已确认方案（回复「1」），直接按确认范围实施。

## 范围与文件

- 修改 `企业数据资产中心-交互原型.html`：两组菜单改为按钮和子菜单，增加独立展开状态；其余菜单位置不变。
- 调整 `tests/asset-center.spec.py`、`tests/asset-search.spec.py`：导航辅助函数先展开父菜单，再点击子页面；在现有浏览器验证中补充关键交互。
- 更新 `outputs/asset-center/原型查看说明.md` 和 `企业数据资产中心-原型包.zip`；截图和证据保存在 `outputs/asset-center/menu/`。

## 实现步骤

1. 两组一级菜单默认收起，分别显示图标、标题和展开箭头，彼此独立。
2. 二级菜单缩进显示；点击一级只控制展开状态，不改变当前页面、筛选、抽屉或阅读位置。
3. 二级页面高亮，所属父菜单保留当前栏目状态；父菜单可手动收起，输入和重绘不会擅自展开。
4. 通过统一导航进入子页面时，自动展开所属父菜单；进入其他页面不重置现有展开状态，刷新恢复默认收起。
5. 保留键盘按钮操作、`aria-expanded`、`aria-controls` 和当前子页面的 `aria-current`，重绘后恢复导航焦点及滚动位置。
6. 桌面窄侧栏仍可通过图标展开和进入子页面，移动端继续使用页面切换下拉框。
7. 运行现有浏览器回归及检索验证，查看桌面和窄屏截图；按项目要求完成独立 Agent 只读复核，最后更新分享包。

## 风险与验收

- 风险：现有测试直接点击始终可见的子菜单，需要按真实用户路径先展开；不通过修改生产可见性迁就测试。
- 不改变资产数据、ID、存储和业务详情；不改客户资料和既有备份，不执行 Git 操作。
- 默认子菜单隐藏且不可通过 Tab 进入；展开/收起不改变内容页，两个菜单可同时展开。
- 子页面高亮及自动展开正确，筛选重绘后手动折叠状态保持，键盘焦点可继续操作。
- 宽窄屏无整页溢出；既有浏览器检查和新增交互检查通过，浏览器无脚本及资源错误。
