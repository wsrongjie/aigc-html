# 企业数据资产中心实施计划

**目标：** 创建可直接打开的独立交互原型，展示跨系统数据留存、常规内容提取、多维浏览与关系追溯。

**架构：** 单页 HTML、CSS、原生 JavaScript。客户、员工、账号、素材版本、发送消息、审核记录分别建模，所有页面共享同一数据源；原始内容和提取结果分别展示。业务系统状态以来源快照呈现。

**技术：** 无框架、无外部 CDN；本地演示媒体；Playwright 无头浏览器验证。

## 范围与文件

- 新建 `企业数据资产中心-交互原型.html`。
- 新建 `assets/` 下专用演示音频与视频。
- 新建 `tests/asset-center.spec.py`，验证关系和主要交互。
- 验证输出位于 `outputs/asset-center/`。
- 保留 `bk/` 及客户原始资料，不执行任何 Git 操作。

## 页面与交互

1. 全部资产：动态统计、关键词、类型、来源、日期筛选，列表与卡片切换。
2. 日期归档：按真实演示记录日期分组，提供类别筛选和详情。
3. 客户、销售档案：查看共享会话、业务时间线、相关资产及账号关系。
4. 营销素材：海报、视频、文字，素材版本、内容提取、使用记录、送审及审核追溯。
5. 文字直播间：场次、公共内容、客户行为与档案回跳。
6. 研报、合同、订单服务、外呼、咨诉退款：专属列表与原始内容、结构化字段、关联记录。
7. 数据来源：来源快照、采集范围、待关联记录，不模拟真实系统接入。
8. 详情抽屉：标签切换、历史回退、关联跳转、原始消息定位。

## 演示规则

- 全部人物与业务内容为虚构演示；不复制资料中的个人信息。
- OCR、语音转写、视频总结明确展示为演示提取结果，不调用真实服务。
- 暂不提供风险评分、意向预测、策略建议、审核决定或退款执行。
- 来源系统原始标识与统一标识同时留存；关系不足显示待关联。
- 不向原有系统写入；素材审核展示对应版本的来源历史。

## 验证与审查

1. 校验 HTML 脚本语法、稳定 ID 唯一性、引用关系及演示统计口径。
2. 浏览器验证筛选、空态、分页/视图、详情标签、跨视角跳转、原始消息定位、版本和审核记录。
3. 验证中文特殊字符搜索、键盘关闭与返回、窄屏、刷新、下载及本地媒体。
4. 检查控制台与未捕获错误；保存桌面及窄屏截图。
5. 按项目要求开展多 Agent 对抗性复核，修复重要问题并定向回归。

## 主要风险

- 内容与每次发送混淆、历史版本被当前版本覆盖。
- 客户/员工视角统计混入无关联记录，公共内容被硬挂客户。
- 来源状态被误认为本模块可处理的业务动作。
- 演示提取结果被误解为实际服务运行结果。

用户已授权在信息充分后直接制作原型，本计划随本轮实施执行。

## 实施与验证结果

- 原型包含 40 项虚构演示资产、6 位客户、3 位销售及1位内容作者，提供12个浏览入口。
- 关键数据链：同一海报3次发送、3位客户、2名销售；历史消息引用实际素材版本。
- 已修复：客户关联内容误开最新稿、公共内容创建事件误挂客户、业务历史节点遗漏、人员账号标识检索、长标题窄屏布局。
- 上传资料写入专用 IndexedDB，文件内容类型及文件头校验；未接入识别服务的上传件标记待提取。PDF原件通过下载查阅。
- Chromium无头浏览器49项检查通过；页面脚本错误、控制台错误、失败资源请求均为0。
- 已检查1440px桌面截图、1280/900/390px页面及320px长标题边界；验证文件直开、本地媒体播放、上传刷新恢复和导出。
- 两名审查Agent完成交叉复核，关键问题已修复并回归。
- 两份原备份SHA-256与实施前一致；未修改客户资料、未执行Git操作。
- 验证报告：`outputs/asset-center/verification.json`；截图位于同目录。
