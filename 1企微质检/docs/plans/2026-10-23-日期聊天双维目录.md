# 日期归档聊天双维目录修改计划

用户已确认本轮修改计划。

## 范围

- 修改 `企业数据资产中心-交互原型.html` 的日期归档聊天视图。
- 补充 `tests/asset-center.spec.py` 的浏览器交互与回归验证。
- 更新查看说明、截图、验证结果及现有原型分享包。
- 原有客户资料和备份不改动，不执行 Git 操作。

## 交互与数据口径

1. 日期在左；右侧为人员目录与当天聊天详情。
2. 销售维度：日期 → 实际销售 → 当天有往来消息的客户 → 对话详情。
3. 客户维度：日期 → 客户 → 当天有往来消息的实际销售 → 对话详情。
4. 双方任一方当天发过消息即计入；目录统计包括收发两侧。
5. 同一实际销售和客户的多个企微账号合并为一个对接目录项；详情保留每条消息的账号来源及原始素材版本。
6. 关键词用于匹配对话目录；选中后展示该对接关系当天的完整消息。来源与日期范围继续约束结果。
7. 日期或维度切换清空具体对话选择；筛选后剔除失效选择。
8. 日期页来源抽屉保留查阅日期；全量会话档案入口仍可查看完整历史。
9. 导出与当前日期、筛选、人员或对话选择一致。
