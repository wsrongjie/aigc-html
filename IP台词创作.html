面向研发与评审：链路位置、字段契约、状态机与边界

1. 链路位置

台词（本页）→主体绑定→分镜→成片

本页产出：主播 IP 风格化的口播台词文本（1–3 篇备选）。下游入口：导演台-批量成片工作台 / step3-分镜管理。

2. 已实现 vs 待接入

环节原型实现待接入
IP 档案前端常量 ipCatalog（2 个 IP，指纹/金句/场景内置）IP 档案服务：样本上传 → 特征蒸馏 → 档案版本化
内容理解正则识别 5 类内容 + 3 类受众 + 首句取核心LLM 结构化抽取（内容类型/受众/核心观点/事实点）
台词生成规则框架 + 开场变体；风格改写为句式替换与结构重排的规则模拟LLM 按 IP 档案生成，结构骨架差异化
合规预检4 类风险词正则 + 风险提示检测合规中台 / 风控词库服务
台词长度控制以字数为口径：精简 ≈130 字 / 标准 ≈200 字 / 详细 ≈320 字；原创模式按字数标尺对照（±15% 达标），改写模式展示「原文 → 改写」字数LLM 按目标字数生成（当前为规则分支实现）
导出TXT / SRT / CSV（浏览器端生成）服务端导出 + 资产库落库

3. 草稿状态机

  • 生成态：generated（已生成 · 待编辑）
  • 编辑态：edited（已编辑，同时保留生成稿与编辑稿双版本，支持“还原生成稿”）
  • 风险态：检出 risk 级风险词 → 待复核 · 检出风险词（红色药丸，优先级高于编辑态展示）
  • 本地持久化：草稿 / 选中 IP / 创作要求 / 表单存入 localStorage（key: ip-script-studio-v1），可从风格面板底部一键清空

4. 字段契约（建议）

  • 输入 brief：mode（generate 智能原创 / rewrite 风格改写）、direction（创作要求）、source（改写原文，rewrite 模式必填）、facts（事实素材）、length（short / standard / detail，由目标字数就近映射）、targetChars（目标字数，可手动输入 120–500，预设 130 / 200 / 320）、goal（营销目标：投教内容 / 直播引流 / 内容涨粉 / 服务推广 / 产品推广，对齐创意 Agent 的 goal 字段；非投教目标在成稿末尾追加 IP 口吻的行动引导）、count（1–5）、ipId
  • 输出 draft：title、text、originalText、status、statusKey
  • 导出 CSV（16 列）：IP、IP档案版本、创作方式、长度档位、营销目标、创作要求/原文、内容类型、受众、标题、台词、字数、预计时长、事实素材、合规预检、生成时间、是否已编辑
  • 交接 ip-script-handoff-v1：送出时写入 localStorage，含 ipName / title / text / chars / seconds / mode / length / targetChars / goal / type / audience / source / compliance / riskHits / at，供下游页面读取

5. 交付动作与目标

  • 送入导演台 → 导演台-批量成片工作台.html（台词与元信息写入交接区 ip-script-handoff-v1，目标页待接入读取）
  • 送合规检查 → 合规检查.html（同上，待审稿件与预检结论随行）
  • 导出 TXT / SRT / CSV → 浏览器端生成，无服务端依赖

6. 边界与约束

  • 场景约束：固定人物角色、固定背景、正面对镜口播、上半身/中近景
  • 本页只负责“说什么”，不负责“怎么拍”；主体绑定与画面构造在分镜环节
  • 与创意Agent 的边界：创意Agent 为无风格锚点的通用创作/改写/拆解；本页为绑定 IP 档案的风格化创作。建议明确为“创意Agent 的特化入口”，避免两个入口做同一件事
  • 库视图的场景标签仅代表推荐度，不代表该 IP 的能力边界（任一 IP 均可生成 5 类内容）
  • 长度以字数控制，不设时长目标：编辑区的“预计口播秒数”由字数 ÷ 4.5 换算而来，仅用于展示，不作为生成依据

7. 已知的模拟降级

  • 生成过程为 4 步分阶段模拟（每步约 320ms），非真实推理
  • “送审 / 送入导演台”确认后打开目标页面，并把台词与元信息写入 localStorage 交接区（ip-script-handoff-v1）；下游页面尚未接入读取
  • 多篇备选共用同一正文骨架，仅开场变体不同（待 LLM 接入后按不同结构生成）
  • 风格改写为规则模拟（句式替换 + 序号重排），只改变表达方式，不保证语义完全等价，仅用于交互演示
  • 台词长度控制目前为规则分支实现（精简保留结论与一条论据、详细追加场景与反例），未按目标字数做模型级生成
  • 合规预检为关键词匹配，仅作为交互占位，不可作为真实风控结论
