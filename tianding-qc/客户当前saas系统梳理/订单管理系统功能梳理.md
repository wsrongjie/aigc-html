## 1. 系统定位与功能全景

从实际页面判断，该系统围绕证券投顾产品销售与服务运营，组织商品、订单、实名、风险测评、合同、回访、服务开通、退款和财务确认等信息；同时提供渠道归因、历史数据查询及咨诉处理入口。

当前账号可见 **5 个一级模块、15 个二级功能入口**，本次均已打开并读取页面主体；另外补看了导入订单的三个标签、合同审核的三种合同、实名审核的两种记录，以及暂停服务操作记录、我的订单更多操作菜单。

| 一级模块 | 二级入口数 | 功能入口 |
| --- | ---: | --- |
| 订单管理 | 7 | 我的订单、暂停服务期订单、合并日志、导流订单、正常订单、退款订单、导入订单 |
| 商品管理 | 3 | 全部商品、商品分类、可售商品 |
| 合规审核 | 2 | 合同审核、实名审核 |
| 财务审核 | 2 | 对公转账审核、退款流水确认 |
| 合规管理 | 1 | 咨诉列表 |

**阅读口径**：下文“提供”“支持”均指界面实际可见的功能设计和操作入口，不代表已执行成功。字段、按钮、业务推断和未验证项分别说明；当前测试数据的条数不用于判断真实业务规模。

## 2. 订单管理

### 2.1 我的订单

用于从当前用户视角检索订单、查看客户成交及履约相关状态。具体“我的”的数据权限范围未验证。

**筛选条件**：

- 客户搜索：搜索类型默认姓名，配套姓名输入框。
- 订单搜索：默认订单号，配套订单编号输入框。
- 商品名称、商品等级、支付状态。
- 时间类型默认支付时间，配套时间范围。
- 员工维度默认订单归属人，配套输入框。
- 订单进度、年龄区间、金额区间。
- 问卷回访状态、人工回访状态、服务开通状态。

**列表信息**：商品信息（可见等级、服务期、赠送期）、价格信息、应付价格、订单号、订单归属人、承接员工、客户信息、订单进度、下单时间、支付状态、问卷回访状态、购买合同审核状态、服务开通状态、人工回访状态、回访合同审核状态、订单备注、激活时间。

**操作入口**：查询、重置、订单导出、列设置、详情；不同记录可见客户专属链接、查看链接、复购、清除实名、更多操作。实际展开的一条“更多操作”菜单包含“复购”“清除实名”。

**状态观察**：

| 状态维度 | 本次页面可见取值示例 |
| --- | --- |
| 实名 | 未实名、已完成实名 |
| 风险测评 | 未风测、风测完成 |
| 签约 | 未签约、已签约 |
| 支付 | 待支付、已支付、已取消、已退款 |
| 问卷回访 | 待回访、回访通过 |
| 购买合同审核 | 待审核、审核通过 |
| 服务 | 待开通、已开通、已关闭 |
| 人工回访 | 免人工介入 |
| 回访合同审核 | 审核通过 |

以上来自不同记录、不同字段，**不能拼接为已经验证的固定状态流**。例如页面存在购买合同待审核但服务已开通的记录，不能直接断言“所有合同审核通过后才可开通服务”。

本次点击一条订单“详情”后，DOM 与截图未呈现可读取的新详情主体；仅确认详情入口存在，内部内容未验证。客户专属链接、复购与清除实名均未执行。

### 2.2 暂停服务期订单

- **筛选**：客户搜索类型（默认姓名）、姓名、订单号、暂停状态。
- **列表字段**：商品信息、订单号、订单归属人、客户信息、服务到期时间、暂停开始时间、暂停状态、操作。
- **入口**：查询、重置、列设置、查看记录；部分暂停中的订单可见“申请恢复”。
- **实际查看的只读弹窗**：“操作记录”，展示操作时间、操作人、操作内容、附件、状态。样本记录可见申请暂停、审核驳回，以及审核中、正常等状态。
- **边界**：未申请暂停或恢复；服务期是否顺延、审批链、可恢复次数与日期计算规则未验证。

### 2.3 合并日志

- **筛选**：客户搜索类型（默认客户姓名）、客户姓名、归集单号、转出单号、合并时间起止、操作人。
- **列表字段**：客户信息、合并时间、归集单 A、转出单 B、合并金额、操作人。
- **可见信息**：日志中呈现归集订单已付金额的前后变化。
- **入口**：查询、重置、列设置、分页。
- **边界**：本页为日志查询，未发现并执行合并操作；哪些订单可合并、跨商品/跨客户限制、余额与服务期处理规则未验证。

### 2.4 导流订单

提供带渠道来源信息的订单查询。

- **筛选**：姓名、订单号、商品名称、商品等级、支付状态、支付时间范围、订单归属人、订单进度；额外可见渠道标签、平台、归属主播、引流媒介、账号类型等来源维度。
- **订单信息**：商品、价格、应付金额、订单号、客户、进度、下单/支付状态、回访、合同审核、服务开通、归属人、激活时间及退款金额/时间。
- **渠道信息**：平台、主播、引流媒介、账号类型、渠道标签、添加企微。
- **入口**：查询、重置、订单导出、展开、列设置、详情、客户专属链接、回访链接、更多操作。
- **边界**：未展开额外筛选、未查看该页更多操作内部；渠道字段不证明已实现完整归因或投放 ROI 计算。

### 2.5 正常订单

- **筛选**：姓名、订单号、商品名称、商品等级、支付状态、支付时间范围、订单归属人、订单进度、问卷回访状态、人工回访状态、服务开通状态、年龄区间、金额区间、渠道标签等。
- **列表**：订单、价格、客户、进度、支付与履约字段；额外展示转化类型、添加承接企微、承接员工、添加服务企微，以及平台、主播、引流媒介、账号类型和退款信息。
- **入口**：查询、重置、订单导出、列设置、详情；不同记录可见客户专属链接、服务升级、复购。
- **边界**：“正常订单”是系统菜单名称，其纳入条件、与“我的订单”“导流订单”的包含/交集关系未验证；服务升级与复购未执行。

### 2.6 退款订单

集中查询退款申请、合同与退款结果。

**筛选**：姓名/昵称、订单编号、退款单号、审核状态、退款状态、申请时间、激活时间、退款时间、退款类型、退款后服务处置、退款方式、订单归属人。

**字段**：订单编号、客户信息、产品名称、订单归属人、实收金额、参考残值金额、退款审核金额、退款方式、退款单号、申请日期、退款类型、退款后服务处置、退款时间、审核状态、合同签约状态、合同审核状态、退款状态、激活时间、退款完成时间。

**入口**：查询、重置、导出已退款订单、列设置、详情、取消退款。

页面提示：审批状态为“已审批”时，可通过“详情”获取退款合同链接发给客户签署。本次未获取或发送合同链接，未取消退款，也未验证退款金额/残值计算、部分退款、多次退款及服务处置规则。

## 3. 商品管理

### 3.1 全部商品

- **筛选**：商品名称、商品等级、商品分类、搜索价格、状态、收银台。
- **字段**：商品编号、商品信息、商品分类、产品类型、收银台、原价、促销立减、销售价格、商品名称-实付价格下限、状态、销售开始/截止时间、企微专属链接。
- **入口**：查询、重置、新增商品、列设置、H5 链接、下架、编辑。
- **页面说明**：商品上架需报备合规同事；本次只记录此业务要求，没有新增或上架。
- **边界**：商品配置表单、上下架生效方式、促销与实付下限约束、审批机制未验证。

### 3.2 商品分类

- 展示序号、分类名称、商品数量、目前在售、创建时间、修改时间、状态。
- 提供新增分类、编辑、列设置及分页入口。
- 未新增、编辑或修改分类状态，分类层级和删除规则未验证。

### 3.3 可售商品

- **筛选**：商品名称、商品分类、搜索价格、商品等级。
- **字段**：商品编号、商品信息、分类、原价、促销立减、销售价格、商品名称-实付价格下限、状态、销售开始/截止时间。
- **销售入口**：员工专属链接、直播专属链接；实际可见 H5 链接、小程序链接按钮。
- **通用入口**：查询、重置、列设置、分页。
- **边界**：未生成、复制、打开或分发链接，链接归因、有效期及下单效果未验证。

## 5. 财务审核

- **入口**：查询、重置、列设置、审核、提交/维护转账信息。
- **边界**：未执行资金审核或维护信息；到账校验、金额匹配、重复流水防控及审核后支付状态同步未验证。

- **入口**：查询、重置、列设置、详情；本次当前列表未观察到可直接执行退款的按钮。
- **页面提示**：待网签表示客户尚未签署协议，请勿点击退款。这反映业务提示，不等同于已验证后端强制拦截。
- **边界**：未打开资金操作表单、未确认或发起退款；退款通道、实际支付接口、幂等、失败补偿与到账时效未验证。

| 退款处理 | 退款订单、退款合同、退款流水确认 | 审批、签署、合同审核、出款之间的强制依赖及异常处理 |
| 线下款项核对 | 对公转账审核、转账资料、支付流水及订单 | 到账核实、重复凭证识别、订单状态同步 |
| 风险事项跟进 | 咨诉列表、处理状态、任务时间、上下文与历史 | 任务指派、复核、逾期及通知规则 |

### 7.2 订单是多个状态维度的组合

页面分别维护或展示实名、风测、签约、支付、问卷回访、人工回访、购买合同审核、回访合同审核、服务开通等维度。退款页面又展示审批、合同签约、合同审核、退款执行和服务处置。因此产品分析时应分别记录这些维度，不宜仅用一个“订单状态”概括全部业务。
