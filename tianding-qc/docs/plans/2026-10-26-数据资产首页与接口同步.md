# 数据资产首页与接口同步调整

用户已确认首页优化，并追加定期接口拉取、快照同步配置及健康状态，移除待关联资料展示与主动上传。

## 范围
- 修改 `数据资产交互设计.html` 的首页、数据来源、对应导出和下钻。
- 保持客户、销售、日期归档时间线布局。
- 新增 `tests/data-asset-board.spec.py`，更新时间线回归中已移除的上传流程。
- 实现材料与截图保存于 `outputs/data-asset-board/`。不执行 Git 操作。

## 实现
1. 首页依次展示六项指标、资产增长与分类、风险趋势与集中分布、重点事项、覆盖与完整性、接口健康摘要。
2. 统一记录索引，区分独立资产、聊天消息、直播动作及审核记录；素材版本与会话容器不重复计总量。
3. 新增明确标识的演示归集时间和风险评估历史；汇总、列表、导出同源。来源业务时间保留原值。
4. 数据来源支持 HTTPS 接口、租户、认证方式、增量游标字段、拉取周期、首轮回溯范围、超时和重试配置。
5. 接口配置持久化仅保存非敏感字段，凭据仅当前会话使用。连接检测和同步均为显式模拟，不请求真实后台，不启动后台任务。
6. 健康状态区分未配置、待检测、模拟正常、模拟异常、已暂停；日志展示批次、结果、记录数、失败原因及最近成功快照。
7. 移除主动上传入口、来源及加载流程，不删除历史 IndexedDB 数据。移除待关联资料专门展示。

## 验证与风险
- 验证分类合计、稳定 ID 去重、期间/存量、变化计数、筛选下钻、导出与空数据。
- 模拟同步幂等：已有来源记录生成新快照，不把同批数据重复计为新增资产。
- 检查配置校验、刷新恢复、凭据不落盘、暂停/恢复、失败/恢复、无真实网络请求。
- 以隔离 Chromium 检查 1440/1024/768/390 布局与键盘操作，回归档案时间线。
- 完成后进行多 Agent 业务口径及交互对抗审查。

## 验证结果
- `python tests/data-asset-board.spec.py` 通过：同源汇总/下钻/导出、期间切换、空数据、无效与未来时间、接口配置、失败恢复、增量水位和凭据边界。
- `python tests/profile-timeline.spec.py` 通过：客户/销售/日期归档节点和完整秒级时间保持，缺秒来源仍显示原始精度。
- 桌面及 1024/768/390 宽度无页面溢出；已查看首页、来源页及手机配置抽屉截图。支持直接打开本地 HTML。
- 两位 Agent 审查发现的关系串联、未来状态混入、无效时间、连接健康遗漏和水位变更问题均已修复并复核。
- 当前仍是本地静态原型；所有接口运行均为模拟，未连接用户后台，也没有创建实际定时任务。
