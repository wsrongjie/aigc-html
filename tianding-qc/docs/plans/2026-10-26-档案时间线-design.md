# 客户与销售档案时间线调整

用户已确认：调整 `数据资产交互设计.html` 的客户、销售档案时间线及相关时间数据；后续追加将按日期归档的右侧时间线同步为相同布局。

- 根据用户修正：沿用按日期归档的竖线和圆点，每个节点完整保留年月日时分秒，不按日期合并；左侧固定时间列、右侧自适应内容列。标题、类型、查看入口同排，正文紧凑排列，长正文可展开。
- 时间展示到秒；静态演示样本补充虚构秒值，来源缺秒时明确标注，不自动补零。新上传记录实际保存秒数，旧上传记录保留原精度。
- 保留倒序与同秒稳定 ID 排序、原消息定位、版本审核及业务详情跳转。
- 独立样式与渲染函数用于客户、销售档案及按日期归档的右侧时间线；保留日期选择、筛选、消息定位以及聊天分类的对话目录。审核详情保持原布局。
- 验证客户/销售记录完整性、账号筛选、逐节点完整时间与竖线圆点、秒数一致性、缺秒、同秒、长文本以及桌面/窄屏布局。
- 风险：演示数据时间被多个入口引用，需要保持一致；历史上传不得伪造秒数；共享组件修改须避免外溢。
