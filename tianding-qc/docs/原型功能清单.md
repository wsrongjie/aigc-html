# 天鼎 AI 智能管理平台 · 原型功能清单 V1.0

> 范围：数据资产中心、营销策划工作台（不含质检工作台）
> 用途：领导汇报 / 客户方案附件
> 图例：✅ 交互完整可演示　⚠️ 规则或模拟实现（非真实模型/接口）　⛔ 已预留未实现

## 一、数据资产中心

定位：跨系统留存、关联、溯源。把企微、订单、合规、直播、投研、外呼六套系统的数据串成"一个客户、一份资产、一条时间线"。
规模：14 个功能页 + 资产详情抽屉 + 4 类二级档案页。

### 1. 数据资产看板 ✅

**1.1 统计范围控制**
- 近 7 日 / 近 30 日切换
- 演示快照时点标明（统计截止时间、区间文案）
- 全部指标可点击下钻

**1.2 经营核心指标（7 个 KPI）**
- 本期新增客户（含其中成交人数与转化率）
- 本期成交笔数（含其中已退款笔数）
- 成交金额（万元，订单实付口径）
- 退款订单数（含其中处理中笔数）
- 退款金额（按退款申请金额）
- 退款率（同期退款 ÷ 同期成交）
- 净成交金额（成交 − 退款）

**1.3 成交与退款趋势**
- 按日双序列折线（成交笔数/金额、退款笔数/金额）
- 逐日数据表

**1.4 退款原因分布**
- 7 类原因占比（服务后亏损、前期夸大营销、服务不到位、内容质量、重复购买、条款理解、资金安排）
- 支持下钻到客户与原始记录

**1.5 商品成交表现**
- 按商品编号统计成交笔数、金额、均价、退款数、退款率

**1.6 退款处理跟进**
- 处理中/未完成清单、申请日期、已停留天数、责任销售

**1.7 资产规模与增长**
- 本期新增归集记录（柱状图 + 逐日明细）
- 12 类分类资产规模（累计 + 本期新增，分类合计等于总量）

**1.8 档案覆盖与完整性**
- 客户目录覆盖率（有业务记录人数 / 目录总数）
- 销售目录覆盖率
- 覆盖客户评估率
- 已支付订单合同齐备率（可下钻缺合同清单）

**1.9 高风险客户与处置**
- 当前高风险客户
- 待处置 / 待指派 / 未评估（分别计项）
- 新增风险 / 风险升级 / 风险缓解（按客户去重）

**1.10 咨诉预警归因**
- 8 类首因占比（亏损、承诺落差、退费、适当性、响应、收费、打扰、条款）
- 一次预警只归一个首因，附建议动作

**1.11 高风险客户三维分布**
- 按团队 / 商品 / 获客渠道，含高风险人数与占比

**1.12 逾期与合规缺口**
- 超期未结事项（有有效截止时间才判超期）
- 截止时间待补事项
- 缺少购买合同的已支付订单

**1.13 统计口径说明**
- 折叠面板，明确成交/退款/归因口径与"毛额""不重复计数"规则

**1.14 下钻清单**
- 统一弹窗、分页、逐条跳转原始资产

### 2. 资产检索 ✅

**2.1 检索能力**
- 名称、客户、员工、原始编号统一关键词检索
- 类型 / 来源 / 日期区间 / 格式 / 客户 / 销售 组合筛选
- 更多筛选展开态

**2.2 结果呈现**
- 已生效条件回显，支持单条移除
- 列表 / 卡片双视图
- 结果计数、按记录时间倒序、分页
- 空态与"清除筛选"

**2.3 输出**
- 导出检索结果索引

### 3. 按日期归档 ✅

- 日期索引（按月分组、每日记录数）
- 当日全类型时间线（聊天消息、素材审核、直播动作、商品配置、订单服务、合同、外呼、咨诉、退款）
- 类型 Tab 过滤 + 来源/日期/关键词筛选
- 记录直达原始资产或消息定位

### 4. 客户档案 ✅

**4.1 客户目录**
- 多身份检索：姓名 / 客户编号 / 手机号 / 企微外部联系人 / UnionID / 小程序标识
- 高级条件：来源系统、对接销售、团队、服务状态、风险等级、时间范围
- 条件回显与单条移除、"有未应用修改"提示
- 分页 + 加载更多
- 列表字段：脱敏手机、来源标识、对接销售、服务状态、风控等级、最近归档更新
- 导出客户索引（手机号自动脱敏）

**4.2 客户档案二级页（8 个 Tab）**
- 客户信息：基础信息、跨系统身份、实名与证件
- 档案总览：完整记录时间线 + 风控状态 + 实际对接人员 + 适当性摘要 + 获客与服务 + 获客来源
- 沟通记录：企微会话原文、附件、按日期分组、双轴（销售/客户）
- 投资者适当性：风险等级、测评有效期、问卷版本、收入/资产/经验/期限/目标等字段，缺失显示"未提供"
- 交易与服务：订单与服务快照、关联商品
- 内容与直播：素材发送、研报阅读、直播动作
- 合同与回访：购买合同、回访确认、签署与审核状态
- 咨诉与退款：事项、退款申请、外呼记录

**4.3 档案操作**
- 档案头部（身份、标签、风控等级、脱敏联系方式、关联范围统计）
- 风险横幅（等级 · 类型 · 判定依据 · 来源记录 · 一键跳转）
- 时间线区间筛选（全部 / 近 7 日 / 近 30 日 / 自定义）
- 记录多选：逐条勾选、Shift 区间、"选择到这里"
- 导出档案

### 5. 销售档案 ✅

**5.1 员工目录**
- 姓名、工号、团队、企微账号数、对接客户数、最近更新
- 搜索、团队筛选、账号数筛选
- 分页、导出员工索引

**5.2 一员工多企微账号**
- 账号列表展开/收起
- 按账号多选筛选，联动下方时间线与"实际对接客户"
- 未关联具体账号的记录单独提示

**5.3 员工档案二级页**
- 概览（团队、角色、账号、客户、记录量）
- 时间线（可按账号过滤）
- 实际对接客户清单

### 6. 内容与资料 ✅

**6.1 营销素材**
- 素材列表（海报/视频/文字/音频），类型与来源筛选
- 版本管理（V1/V2…）、逐版本审核状态
- 原件预览 + 结构化提取文本 + 内容描述
- 发送使用记录（谁发给哪个客户、用哪个版本）

**6.2 文字直播间**
- 场次列表、场次档案（老师、公共内容条数、客户动作条数）
- 公共发言原文
- 客户动作独立 Tab（进入/评论，时间与内容）

**6.3 每日研报**
- 研报原文、目录结构、归档时间
- 发送记录与关联客户

**6.4 合同档案**
- 购买合同、回访确认、退款协议、服务申请附件
- 签署状态、OCR 结果、复审状态与审核人
- 关联订单与退款单

### 7. 业务记录 ✅

**7.1 商品档案**
- 商品配置、价格、等级、状态、来源更新时间
- 配置变更历史
- 关联订单明细（成交销售、下单快照、实付、服务期间、赠送期）
- 成交客户与成交销售去重统计
- 只按来源商品编号关联，不按同名推断；导出商品索引

**7.2 订单与服务**
- 订单快照（商品、实付、支付状态、服务状态、服务期间）
- 合同与回访关联、退款申请与执行结果
- 服务暂停/退款不覆盖原服务状态

**7.3 外呼记录**
- 呼叫方向、时长、接通状态、关联事项
- 录音播放与转写文本

**7.4 咨诉与退款**
- 咨诉事项：来源分类、事项状态、处理人员、处理说明、任务截止
- 退款申请：申请金额、原因、执行状态、关联订单与退款协议
- 处理历史时间线

### 8. 数据来源管理 ⚠️

- 6 个来源系统清单（企微会话存档、订单系统、合规系统、文字直播、投研内容库、外呼服务），含接入范围与最近快照
- 接口配置：服务地址、租户、鉴权方式、同步周期、回溯天数、游标字段、超时、重试、启停
- 连接检测 / 同步模拟 / 运行日志（三类动作，模拟结果）
- 健康状态（未配置 / 待检测 / 模拟正常 / 模拟异常 / 已暂停）与下次计划时间
- 配置本地持久化、暂停后历史快照与日志保留

### 9. 资产详情与通用能力 ✅

**9.1 资产详情抽屉**
- 原始内容预览（图片/视频/音频/文本）
- 结构化内容（提取文本 + 内容描述）
- 关联记录（客户、员工、订单、合同、会话、直播）
- 关联商品（按来源商品编号）
- 送审与审核（送审范围、审核人、审核时间、来源位置、来源记录、审核意见）
- 来源与版本（统一资产 ID、来源系统、来源记录 ID、采集方式、原件状态、文件信息、版本列表）
- 版本切换器（当前查阅版本 + 状态）

**9.2 对话视图**
- 按日期分组的会话原文
- 销售/客户双轴切换、附件卡片、消息定位与高亮

**9.3 评测上下文导出 ⚠️**
- 在客户时间线上勾选记录 → 生成评测包
- 3 类任务模板：投诉意向判断、客户画像、服务风险归因
- JSON Schema 预览、匿名化开关、盲评开关
- 一键复制 / 下载
- （真实模型调用与结果回填未实现）

**9.4 平台通用能力**
- 全局搜索（Enter 进入资产检索）

- 键盘可访问（focus-visible、aria、Tab 序列）

## 二、营销策划工作台

定位：面向营销策划负责人，把"销售怎么用素材"与"客户怎么反馈"连起来，形成 **使用 → 效果 → 复盘 → 创作** 的闭环。
规模：4 个功能页 + 素材详情页；15 份素材（12 份演示 + 3 份客户真实原始素材）。

### 1. 效果总览 ✅

**1.1 范围控制**
- 近 7 天 / 近 30 天
- 团队筛选（全部 / 华东一组 / 华东二组 / 华南一组）
- 客户阶段筛选（初次咨询 / 需求沟通 / 异议处理 / 成交推进）
- 触达期与 7 天观察窗口说明

**1.2 核心指标卡（5 个主指标 + 2 个辅助）**
- 采用素材的销售（人 / 团队总人数）
- 触达客户数（跨素材、跨企微账号按客户去重）
- 客户开口率（24 小时内开口客户 ÷ 触达客户）
- 3 日关联支付率
- 7 日关联支付率
- 辅助：累计发送次数、使用素材份数

**1.3 客户响应趋势**
- 开口率与有效沟通率双线趋势
- 按天 / 每 3 天聚合

**1.4 本期值得关注**
- 自动识别高开口率素材，给出进入下一轮复盘的建议

**1.5 素材排名**
- Top 榜（仅样本 ≥ 80 人参与排名）
- 小样本素材单独提示

**1.6 输出**
- 导出效果报表

### 2. 素材效果库 ✅

- 搜索（名称 / 编号 / 主题 / 来源文件名）
- 素材形式筛选
- 排序：客户开口率 / 3 日关联支付率 / 7 日关联支付率 / 使用次数
- 新增原始素材置顶并标注
- 列表字段：排名、封面、素材名、编号、形式、阶段、版本、使用销售、触达客户、开口率、3 日/7 日支付率、样本状态
- 样本状态分级：暂无样本 / 样本不足 / 可供复盘
- 分页、导出当前结果

### 3. 素材详情 ✅

**3.1 素材概览**
- 封面、编号、版本、客户阶段、样本状态
- 正文摘要与表达结构
- 合规关注标签（个股名称、收益暗示、付费引导、免责声明等）

**3.2 核心指标**
- 累计使用次数 / 采用销售数、触达客户、开口率、3 日/7 日关联支付率、关联退款
- 每个指标带口径说明

**3.3 原始素材来源**
- 来源文件、页码、素材类型、责任人、执业编号、日期
- 风险标签汇总
- 原文摘录弹窗（含"仅作演示引用，不构成投资建议"声明）

**3.4 使用分析**
- 销售采用率（已采用人数 / 团队总人数）
- 按销售的使用次数、触达、开口率、支付客户
- 销售搜索
- 单销售使用记录

**3.5 客户表现漏斗**
- 触达客户 → 24h 开口 → 有效沟通 → 3 日支付 → 7 日支付

**3.6 客户反馈明细**
- 每位客户一行，聚合多次触达
- 字段：客户编号、销售/团队、触达次数、窗口内反馈、关联支付笔数、最近触达时间
- 按客户编号精确搜索、按销售搜索、反馈筛选、排序
- 分页（20 / 50 / 100）
- 点击客户打开使用记录抽屉（时间线：发送 → 客户回复 → 支付）

**3.7 使用话术对比**
- 提问式开场 vs 直接介绍的效果差异

### 4. 素材复盘 ✅

**4.1 素材选择**
- 选择器弹窗：搜索、按阶段/形式筛选
- 批量全选 / 取消当前筛选结果
- 已选计数、至少 2 份
- 已选素材移除、清空
- 选择变更不影响已生成的复盘内容

**4.2 横向对比**
- 按客户阶段分组的对比表
- 列：触达客户、开口率、有效沟通率、3 日/7 日关联支付率、表达结构、样本状态
- 明确"仅在同组内比较、客户数不可直接相加"

**4.3 深度复盘（阶段 × 主题分组）**
- 分组条件：每组至少 2 份素材、各 ≥ 80 位触达客户
- 逐份诊断：开口/触达、承接/已开口、3 日/7 日支付，输出运营动作与判断依据
- 使用结构：共同触达客户数及占比、提问式开场占比、Top3 销售发送集中度
- 分组拆解：按开场话术 / 销售人员 / 发送时段 / 前后周期，展示双方分子分母、差值（pp）、样本是否达标
- 反馈证据：进一步沟通 / 询问服务 / 其他回复 / 未回复四类互斥计数，可查看证据记录
- 下一版实验设计：待验证解释、单一改动、新旧版对照、客户分组方式、主指标、保护指标、结束规则
- 组内优化方案复制 / 带入素材评估

**4.4 输出**
- 导出完整复盘报告（Markdown）
- 证据弹窗（指标口径、素材正文、最近使用记录）

### 5. 素材评估与优化 ⚠️

**5.1 第一步：提交运营初稿**
- 素材类型切换：文字文案 / 海报图片 / 视频片段
- 评估方向配置（文字 3 项、海报 4 项、视频 4 项）
- 渠道、画面比例、目标时长
- 文件上传：TXT/MD ≤100KB、PNG/JPG/WEBP ≤8MB、MP4/WEBM ≤30MB，支持拖拽与本机预览
- 正文/脚本编辑（≤12,000 字符，实时字数提示）
- 使用背景：目标客户阶段、素材形式、内容主题、希望客户采取的行动、市场背景、必须保留的原文
- 历史参考范围：参考团队、触达天数
- 从复盘带入参考素材与优化方向
- 草稿自动保存 + 手动保存

**5.2 第二步：评估与建议**
- 匹配同阶段同主题历史素材，优先同形式
- 历史案例卡：触达、开口率、有效沟通率、3 日/7 日关联支付、表达结构
- 修改建议清单：建议层级、问题描述、原稿位置、建议改法、数据依据
- 逐条勾选采纳
- 媒体素材标注"待解析"（未接 OCR/ASR/视频理解）
- 评估过期提示（初稿或背景变更后自动失效）
- 保留原稿进入审阅

**5.3 第三步：审阅优化稿**
- 双栏对比（运营初稿 vs 优化版本）
- 标题、正文可继续人工编辑
- 必须保留原文缺失校验
- 版本标记（优化 / 保留原稿、V1）
- 复制正文、导出素材稿、导出评估依据
- 确认版本 → 状态进入"待投放验证"
- 验证建议：同阶段客户小范围使用、记录素材版本/销售话术/发送时机、统一观察窗口
