# 抖音 / 快手平台对接流程接口清单

日期：2026-07-16  
适用场景：企业 / 机构号提前授权绑定后，在视频平台内选择视频并分发到抖音、快手账号。

## 1. 总体结论

- 快手：公开文档已支持后台上传并发布视频，可按“授权 -> 上传 -> 发布 -> 查询状态”做完整自动分发。
- 抖音：公开能力可确认 OAuth 授权、投稿/分享、Webhook 等；服务端后台直发视频需要平台明确开通权限和正式接口文档。当前产品上应先按“端内投稿 / 手动确认”设计。
- 研发实现时，前端只创建任务和展示状态；平台 token、上传、发布、查询、Webhook 都应由后端完成。

## 2. 平台应用准备

### 你们平台接口

```http
POST /api/external-platform-apps
GET  /api/external-platform-apps
PUT  /api/external-platform-apps/{appId}
```

保存字段：

```text
platform
app_id / client_key
app_secret
redirect_uri
webhook_url
scopes
status
```

### 平台侧配置

| 平台 | 需要配置 |
| --- | --- |
| 抖音 | 创建应用、配置 OAuth 回调地址、配置 Webhook、申请 `user_info`、投稿/发布相关能力 |
| 快手 | 创建网站应用、配置 OAuth 回调地址、申请 `user_info`、`user_video_publish`、`user_video_info` |

## 3. 用户发起账号绑定

### 你们平台接口

```http
POST /api/external-bindings/{platform}/authorize-url
```

后端生成：

```text
OAuth 授权 URL
state
redirect_uri
scope
```

`state` 必须一次性使用，用于防 CSRF，并关联 `tenant_id`、`user_id`、`platform`。

### 抖音授权入口

```http
GET https://open.douyin.com/platform/oauth/connect/
```

常用参数：

```text
client_key
response_type=code
scope
redirect_uri
state
```

### 快手授权入口

网页授权：

```http
GET https://open.kuaishou.com/oauth2/authorize
```

扫码授权：

```http
GET https://open.kuaishou.com/oauth2/connect
GET https://open.kuaishou.com/oauth2/qr_code
```

常用参数：

```text
app_id
scope
response_type=code
redirect_uri
state
ua=pc
```

## 4. 授权回调与 token 入库

### 你们平台回调接口

```http
GET /api/external-bindings/{platform}/callback
```

接收：

```text
code
state
```

处理：

```text
校验 state
-> 用 code 换 access_token / refresh_token
-> 保存 open_id、scopes、token 到期时间
-> 标记绑定状态为 bound
```

### 抖音 code 换 token

```http
POST https://open.douyin.com/oauth/access_token/
```

参数：

```text
client_key
client_secret
code
grant_type=authorization_code
```

返回核心字段：

```text
access_token
refresh_token
open_id
scope
expires_in
```

### 快手 code 换 token

```http
GET https://open.kuaishou.com/oauth2/access_token
```

参数：

```text
app_id
app_secret
code
grant_type=authorization_code
```

返回核心字段：

```text
access_token
expires_in
refresh_token
refresh_token_expires_in
open_id
scopes
```

建议落库表：

```text
external_account_binding
```

关键字段：

```text
platform
external_open_id
external_name
access_token_encrypted
refresh_token_encrypted
access_token_expires_at
refresh_token_expires_at
scopes
status
```

## 5. token 刷新

### 你们平台接口

```http
POST /api/external-bindings/{bindingId}/refresh
```

### 抖音刷新 token

```http
POST https://open.douyin.com/oauth/refresh_token/
```

抖音 refresh token 续期：

```http
POST https://open.douyin.com/oauth/renew_refresh_token/
```

### 快手刷新 token

```http
GET https://open.kuaishou.com/oauth2/refresh_token
```

参数：

```text
app_id
app_secret
refresh_token
grant_type=refresh_token
```

注意：

- token 刷新必须后端完成。
- refresh token 不能进前端、日志、埋点。
- 快手刷新后旧 refresh token 会废弃，必须串行刷新，避免并发刷新导致 token 失效。

## 6. 用户创建发布任务

用户在视频资产中选择视频，填写标题、文案、话题、封面、可见范围后，点击“创建发布任务”。

### 单视频分发

```http
POST /api/videos/{videoId}/distribution-tasks
```

### 批量分发

```http
POST /api/videos/distribution-tasks:batch
```

请求示例：

```json
{
  "platforms": ["kuaishou", "douyin"],
  "title": "今日市场观点",
  "caption": "这是一段投顾短视频文案",
  "topics": ["AI生成", "投顾观点"],
  "coverAssetId": "cover_123",
  "visibility": "public"
}
```

任务拆分规则：

```text
1 个视频 x 2 个平台 = 2 个发布任务
3 个视频 x 2 个平台 = 6 个发布任务
```

建议使用幂等键：

```text
tenant_id + video_version_id + binding_id + platform + content_hash
```

## 7. 快手后台发布链路

### 7.1 发起上传

```http
POST https://open.kuaishou.com/openapi/photo/start_upload
```

Query：

```text
access_token
app_id
```

scope：

```text
user_video_publish
```

返回：

```json
{
  "result": 1,
  "upload_token": "xxx",
  "endpoint": "uploader.xxx.com"
}
```

### 7.2 上传视频

小文件二进制上传：

```http
POST http://{endpoint}/api/upload?upload_token={upload_token}
Content-Type: video/mp4
```

小文件 multipart 上传：

```http
POST http://{endpoint}/api/upload/multipart?upload_token={upload_token}
Content-Type: multipart/form-data
```

大文件分片上传：

```http
POST http://{endpoint}/api/upload/fragment?upload_token={upload_token}&fragment_id={index}
GET  http://{endpoint}/api/upload/resume?upload_token={upload_token}
POST http://{endpoint}/api/upload/complete?upload_token={upload_token}&fragment_count={count}
```

注意：

- 分片 ID 从 0 开始。
- 建议每片不超过 10MB。
- 上传成功不等于发布成功，发布阶段仍可能因为转码或文件损坏失败。

### 7.3 发布视频

```http
POST https://open.kuaishou.com/openapi/photo/publish
```

Query：

```text
access_token
app_id
upload_token
```

Body：

```text
cover
caption
stereo_type，可选
merchant_product_id，可选
```

返回核心字段：

```text
photo_id
caption
cover
play_url
create_time
pending
```

状态处理：

```text
pending=false -> published
pending=true  -> platform_processing，后续查询状态
```

### 7.4 查询视频状态

查询列表：

```http
GET https://open.kuaishou.com/openapi/photo/list
```

查询单个视频：

```http
GET https://open.kuaishou.com/openapi/photo/info
```

Query：

```text
access_token
app_id
photo_id
```

查询数量：

```http
GET https://open.kuaishou.com/openapi/photo/count
```

删除视频：

```http
POST https://open.kuaishou.com/openapi/photo/delete
```

## 8. 抖音发布链路

### 8.1 当前建议方案：端内投稿 / 手动确认

你们平台先创建抖音发布任务：

```http
POST /api/videos/{videoId}/distribution-tasks
```

任务状态：

```text
manual_confirmation_required
```

前端提示：

```text
请前往抖音端内完成投稿确认
```

用户确认完成后：

```http
POST /api/distribution-tasks/{taskId}/confirm-manual
```

后端推进状态：

```text
manual_confirmation_required
-> platform_processing / published
```

### 8.2 后续可扩展：抖音服务端后台直发

只有拿到抖音正式开放权限和接口文档后再补齐：

```text
Douyin upload video API
Douyin publish video API
Douyin query video status API
Douyin delete video API
```

当前不要在研发实现中写死未确认的抖音后台直发接口。

## 9. Webhook 状态同步

### 你们平台 Webhook 接口

```http
POST /api/webhooks/kuaishou
POST /api/webhooks/douyin
```

### 快手 Webhook

请求体核心字段：

```text
data
message_id
event
app_id
timestamp
```

请求头：

```text
kwaisign
```

处理要求：

```text
验签
message_id 去重
更新任务状态
返回 HTTP 200 + result=1
```

### 抖音 Webhook

请求头：

```text
X-Douyin-Signature
```

签名规则：

```text
sha1(client_secret + body)
```

处理要求：

```text
验签
事件去重
更新任务状态
Webhook 失败时由轮询兜底
```

## 10. 任务查询、重试和取消

### 查询任务

```http
GET /api/videos/{videoId}/distribution-tasks
GET /api/distribution-tasks/{taskId}
```

### 重试任务

```http
POST /api/distribution-tasks/{taskId}/retry
```

### 取消任务

```http
POST /api/distribution-tasks/{taskId}/cancel
```

可自动重试：

```text
网络超时
平台 5xx
上传分片失败
临时限流
```

不可自动重试：

```text
授权过期
scope 不足
账号封禁
视频规格不合规
平台拒发
抖音用户取消确认
```

## 11. 任务状态机

建议状态：

```text
queued
refreshing_token
uploading
submitting
platform_processing
manual_confirmation_required
retry_scheduled
published
platform_rejected
auth_expired
failed
```

典型快手流转：

```text
queued
-> refreshing_token
-> uploading
-> submitting
-> platform_processing
-> published / failed
```

典型抖音流转：

```text
queued
-> manual_confirmation_required
-> platform_processing / published / failed
```

## 12. 完整链路汇总

```text
1. 创建平台应用配置
POST /api/external-platform-apps

2. 获取授权链接
POST /api/external-bindings/{platform}/authorize-url

3. 平台 OAuth 授权
抖音: GET https://open.douyin.com/platform/oauth/connect/
快手: GET https://open.kuaishou.com/oauth2/authorize

4. 授权回调
GET /api/external-bindings/{platform}/callback

5. code 换 token
抖音: POST https://open.douyin.com/oauth/access_token/
快手: GET  https://open.kuaishou.com/oauth2/access_token

6. 刷新 token
抖音: POST https://open.douyin.com/oauth/refresh_token/
快手: GET  https://open.kuaishou.com/oauth2/refresh_token

7. 创建发布任务
POST /api/videos/{videoId}/distribution-tasks

8. 快手发起上传
POST https://open.kuaishou.com/openapi/photo/start_upload

9. 快手上传文件
POST http://{endpoint}/api/upload
POST http://{endpoint}/api/upload/multipart
POST http://{endpoint}/api/upload/fragment

10. 快手发布视频
POST https://open.kuaishou.com/openapi/photo/publish

11. 快手查询状态
GET https://open.kuaishou.com/openapi/photo/info

12. 抖音端内确认
POST /api/distribution-tasks/{taskId}/confirm-manual

13. Webhook 同步
POST /api/webhooks/kuaishou
POST /api/webhooks/douyin

14. 重试
POST /api/distribution-tasks/{taskId}/retry
```
